# Project documents

The existing Project Charter is preserved in its original location at the project root. An identical local copy is organized under `docs/local/`. Word documents and `docs/local/` are excluded from version control because the charter contains personal identifiers and named individuals.

Add repository-safe planning documents here when they are ready. Review every document for personal information, confidential details and unsupported claims before staging it. The root README summarizes the planned project scope and objectives without those identifiers.

The draft's stakeholder confirmation and formal acceptance remain pending. This repository does not provide evidence of approval, testing, user feedback or completed development.
