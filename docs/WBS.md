# DevSOS Work Breakdown Structure

## Purpose and basis

This WBS breaks the DevSOS project into 18 work packages covering planning, design, development, testing and handover. It follows Project Charter version 0.1, dated 18 November 2026. The planned project period is 18 November to 1 December 2026, inclusive.

The completion criteria are planned targets; stakeholder participation and acceptance remain pending. The project manager is responsible for all work packages. The representative and volunteer learners provide input and review once their participation is confirmed.

## Scope and structure

The seven main deliverables cover the full project scope, including project management and closure. Their work packages separate the outputs so that the same work is not counted twice.

DevSOS will be a static HTML, CSS and JavaScript website with three pages and four troubleshooting guides. The scope excludes AI diagnosis, automatic problem detection, accounts, databases, backend services, website execution of terminal commands, private student records, a mobile app, paid custom domains and a large guide library. The website may be demonstrated locally or hosted using a suitable free service.

## Planning dependencies

Requirements guide the page designs and selection of troubleshooting topics. The pages and guides are brought together before final testing and stakeholder review. Monitoring continues throughout the project, and the final records form the handover and closure pack.
